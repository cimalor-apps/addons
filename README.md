# Cimalor — Odoo Apps

Free and open source Odoo modules by [Cimalor](https://cimalor.com), published on the
Odoo Apps Store.

One branch per Odoo series, named after it. This branch targets **Odoo 18.0**, and every
module here declares an `18.0.x.y.z` version. Each module lives in its own folder at the
root of the branch. The same modules for Odoo 19.0 live on the `19.0` branch.

## Modules

| Module                      | Name                     | What it does                                                                                          |
| --------------------------- | ------------------------ | ----------------------------------------------------------------------------------------------------- |
| `cimalor_team_todo`         | Team To-Do               | Shared to-do lists for the whole team: shared stages, one owner per task, no Project app needed       |
| `cimalor_team_todo_project` | Team To-Do: Project link | Optional companion that links team tasks to real projects. Installs itself when both apps are present |

## Installation

Clone this branch into your Odoo addons path, restart Odoo, update the apps list and
install the module from the Apps menu. Or install it straight from the Odoo Apps Store.
